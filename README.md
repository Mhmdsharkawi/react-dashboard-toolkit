# React Dashboard Toolkit

A modern, responsive analytics dashboard UI toolkit built with **React 18**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## Features

- 📊 **Metric Widgets**: KPI cards with dynamic trend badges and sparkline previews.
- 📈 **Interactive Charts**: Responsive SVG/Canvas charts for revenue and engagement metrics.
- 📋 **Data Tables**: Paginated, sortable tables with column filters and quick search.
- 🌓 **Theme Switcher**: Dark and light modes with system preference sync.
- 📱 **Mobile Ready**: Adaptive drawer navigation and responsive breakpoints.
